# Homebrew Tap for Mooziac

Official Homebrew tap for [Mooziac](https://github.com/shirkeharsh/mooziac) — Native macOS menu bar music player for YouTube Music and local audio.

## Installation

```bash
brew install shirkeharsh/tap/mooziac
```

Or tap first:

```bash
brew tap shirkeharsh/tap
brew install --cask mooziac
```

## Updates

To upgrade Mooziac to the latest version:

```bash
brew update
brew upgrade --cask mooziac
```

## Uninstall

```bash
brew uninstall --cask mooziac
```
